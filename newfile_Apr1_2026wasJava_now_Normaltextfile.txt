To configure the port range for Apache Ignite 
TCP_Discovery_IP_Finder, set the localPortRange property on the TcpDiscoverySpi bean in your Ignite configuration. The port ranger 
determines how many ports, starting from localPort, the node will try to bind(捆绑/装订/约束/强迫/团结) to for discovery. 
Setting Port Range in Configuration. You can define this in XML or Java:
{
TcpDiscoverySpi spi = new TcpDiscoverySpi();
// Sets the local port to 47500 and checks 100 ports (47500-47599)
spi.setLocalPort(47500);
spi.setLocalPortRange(100); 

IgniteConfiguration cfg = new IgniteConfiguration();
cfg.setDiscoverySpi(spi);
}
