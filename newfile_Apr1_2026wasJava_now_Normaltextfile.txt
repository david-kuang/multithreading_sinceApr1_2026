1ODBC Ignite Driver, how to install.
1(1)To install the Apache Ignite ODBC driver on Windows, run the pre-built .msi installer package or execute the manual install script from %IGNITE_HOME%/platforms/cpp/odbc/install. 
On Linux, build the driver from source using CMake and register it via odbcinst with ignite-odbc-install.ini.

(2)Windows Installation
. Using MSI: Run ignite-odbc-amd64.msi (64-bit) or ignite-odbc-x86.msi (32-bit).
. Manual Script: Place the driver DLL in your chosen folder, verify dependencies are in %PATH%, and run the setup script inside %IGNITE_HOME%/platforms/cpp/odbc/install
 .Configure DSN: Open the ODBC Data Source Administrator (odbcad32 or odbc64), click Add, select Apache Ignite, and complete your connection settings.

(3)Linux Installation
. Prerequisites: Install CMake (3.6+), GCC/Clang, OpenSSL, and unixODBC
. Build Driver: Navigate to $IGNITE_HOME/platforms/cpp, create a build folder, run cmake .. -DWITH_ODBC=ON, and build/install using cmake --build . --target install
. Register Driver: Verify shared library links with ldd /usr/local/lib/libignite-odbc.so
. Install INI: Update the file path in $IGNITE_HOME/platforms/cpp/odbc/install/ignite-odbc-install.ini
. Register with System: Run sudo odbcinst -i -d -f $IGNITE_HOME/platforms/cpp/odbc/install/ignite-odbc-install.ini.

### Apache Ignite 2.x — ODBC installation

The Ignite 2 ODBC driver is a native driver used by applications such as **Excel, Power BI, Python, C/C++, and other ODBC clients**. The driver name is:

```text
Apache Ignite
```

and the typical connection string is:

```text
DRIVER={Apache Ignite};ADDRESS=localhost:10800
```

([Apache Ignite][1])

#### Windows

1. Download the Apache Ignite 2.x distribution from the [Apache Ignite Downloads page](https://ignite.apache.org/download.cgi?utm_source=chatgpt.com).
2. Locate the ODBC driver in the Ignite distribution.
3. Install the appropriate **64-bit ODBC driver** for a 64-bit application.
4. Open:

```text
ODBC Data Sources (64-bit)
```

5. Go to **System DSN → Add**.
6. Select:

```text
Apache Ignite
```

7. Configure:

```text
Server/Address: localhost
Port: 10800
```

8. Test the connection.

Apache's documentation specifically notes that Windows DSNs are configured through the ODBC Data Source Administrator (`odbcad32`/64-bit ODBC administrator). ([Apache Ignite][1])

### Important: Ignite server port

For Ignite 2.x, the SQL/ODBC endpoint normally listens on:

```text
10800
```

So if your Ignite node is running locally, the basic connection is:

```text
DRIVER={Apache Ignite};ADDRESS=localhost:10800
```

([Apache Ignite][2])

### Linux

If you're installing on Linux with `unixODBC`, you typically configure:

```text
/etc/odbcinst.ini
/etc/odbc.ini
```

You can find the active ODBC configuration locations with:

```bash
odbcinst -j
```

Then define a DSN such as:

```ini
[Ignite]
description=Apache Ignite
driver=Apache Ignite
ADDRESS=localhost:10800
```

([Apache Ignite][1])

### If you are using Ignite 3

```text

```

For example:

```text
DRIVER={Apache Ignite 3};ADDRESS=localhost:10800
```

([Apache Ignite][3])
